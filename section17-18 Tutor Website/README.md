## Sections on the Page
1. **Navbar** — Responsive navigation with mobile hamburger menu
2. **Hero** — Full-width header with CTA button and SVG wave decoration
3. **Learn Section** — 8-topic image grid of course subjects
4. **Chapters** — 3 chapter overview cards with custom SVG icons
5. **Course Summary** — Detailed 3-column list breakdown
6. **Info** — "Who is this course for?" with background image split
7. **Takeaways** — 6 key benefit cards with Font Awesome icons
8. **Course Details** — Image + content two-column section
9. **Author Info** — Author profile section with skill highlights
10. **Stats** — Numbers showcase (users, reviews, case studies)
11. **Newsletter** — Email subscription form
12. **Social** — Social media icon links
13. **Footer** — Footer links and copyright

## Features
- ✅ Fully responsive layout (mobile, tablet, desktop)
- ✅ Animated mobile hamburger menu with slide-down drawer
- ✅ SVG wave frame decoration on hero section
- ✅ CSS custom properties for consistent theming
- ✅ Accessible navigation with ARIA attributes (`aria-expanded`, `aria-label`, `role`)
- ✅ Font Awesome icons throughout
- ✅ Google Fonts (Open Sans)

## Skills Applied
- Semantic HTML5 with full accessibility (ARIA roles, labels)
- CSS Flexbox for all major layouts
- Responsive design with media queries
- CSS custom properties (variables)
- CSS transitions and hover effects
- Vanilla JavaScript for mobile menu toggle
- SVG integration (inline and `<img>`)
