# Section 9 — Landing Form Mini-Project

## Overview
A complete responsive landing form interface built from scratch, applying HTML structure and CSS styling skills from previous sections.

## Project Structure

```
section9 Landing Form/
├── index.html       # Main HTML structure
├── css/
│   └── style.css    # Styles
└── images/          # Background and asset images
```

## Features
- Responsive form layout with modern styling
- Background image with overlay
- Styled input fields, labels, and submit button
- Clean, centered layout using Flexbox

## Skills Applied
- HTML form elements and attributes
- CSS Box Model, Flexbox layout
- Responsive design with percentage-based sizing
- Background images with `background-size: cover`
- Typography using Google Fonts
