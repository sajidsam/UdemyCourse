# Section 3 — HTML Forms and Input Elements

## Overview
This section covers everything you need to know about HTML forms — from basic text inputs to advanced form controls. Forms are essential for user interaction on the web.

## Topics Covered

| Folder | Topic |
| :----- | :---- |
| `01-text-based-inputs` | `<input type="text">`, `<input type="email">`, `<input type="password">` |
| `02-text-input-attributes` | `placeholder`, `required`, `minlength`, `maxlength`, `pattern`, `autofocus` |
| `03-select-and-textarea` | `<select>` dropdowns, `<option>`, `<optgroup>`, `<textarea>` |
| `04-checkboxes-and-radio` | `<input type="checkbox">`, `<input type="radio">`, grouping with `name` |
| `05-other-input-types` | `date`, `time`, `color`, `range`, `number`, `file`, `hidden`, `submit` |
| `06-datalist` | `<datalist>` for autocomplete suggestions |
| `06-html-form-challenge` | Practice challenge: build a complete HTML form |

## Key Concepts
- The `<form>` element: `action`, `method` attributes
- Labels with `for` / `id` pairing for accessibility
- Form validation using HTML attributes
- `<fieldset>` and `<legend>` for grouping related fields
