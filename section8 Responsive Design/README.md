# Section 8 — Responsive Design

## Overview
This section teaches you how to build websites that look great on every screen size — from mobile phones to large desktops. It covers fluid layouts, viewport units, media queries, and modern container queries.

## Topics Covered

| Folder | Topic |
| :----- | :---- |
| `01-flexible-layouts-percentages` | Using `%` widths for fluid, proportional layouts |
| `02-rem-em-units` | `rem` (root-relative) vs `em` (parent-relative) for scalable typography and spacing |
| `03-viewport-units` | `vw`, `vh`, `vmin`, `vmax` — sizing relative to the viewport |
| `04-media-queries` | `@media` breakpoints, `min-width` (mobile-first) vs `max-width` |
| `05-responsive-pricing-grid` | 🏗️ Challenge: responsive pricing grid using Flexbox + media queries |
| `06-responsive-flexbox-layouts` | Real-world responsive layouts with Flexbox |
| `07-container-queries` | Modern `@container` queries — component-level responsiveness |
| `08-container-units` | `cqi`, `cqw`, `cqb`, `cqh` — sizing based on container dimensions |

## Key Concepts
- **Mobile-first design**: start with small screens, enhance for larger
- `rem` for consistent, accessible font sizing
- Breakpoints: common values `480px`, `768px`, `1024px`, `1200px`
- Container Queries: respond to parent container size, not just viewport
- The difference between `em` and `rem` in real-world usage
