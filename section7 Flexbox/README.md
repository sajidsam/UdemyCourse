# Section 7 — Flexbox

## Overview
This section covers CSS Flexbox — the most powerful one-dimensional layout system in CSS. You'll learn how to align, distribute, and reorder elements with ease, and apply your knowledge through two layout challenges.

## Topics Covered

| Folder | Topic |
| :----- | :---- |
| `01-flex-container-items` | `display: flex`, flex container vs flex items, main axis vs cross axis |
| `02-align-and-justify` | `justify-content`, `align-items`, `align-content`, `align-self` |
| `03-flex-properties` | `flex-grow`, `flex-shrink`, `flex-basis`, `flex` shorthand, `flex-wrap`, `gap` |
| `04-flex-order` | `order` property to reorder items visually |
| `05-flexbox-layout-challenge` | 🏗️ Challenge: build a page layout using Flexbox |
| `06-pricing-card-challenge` | 🏗️ Challenge: build a responsive pricing card grid with Flexbox |

## Key Concepts
- Flex container properties vs flex item properties
- `justify-content`: `flex-start`, `flex-end`, `center`, `space-between`, `space-around`, `space-evenly`
- `align-items`: `stretch`, `flex-start`, `flex-end`, `center`, `baseline`
- `flex: 1` for equal-width flex children
- `flex-wrap: wrap` for responsive layouts without media queries
- `gap` for spacing between flex items (no margin hacks)
