# Section 6 — Box Model and Positioning

## Overview
This section is fundamental to understanding CSS layout. You'll master the CSS box model, learn how all elements are sized and spaced, and explore the positioning system with two real mini-projects.

## Topics Covered

| Folder | Topic |
| :----- | :---- |
| `01-sizing-and-overflow` | `width`, `height`, `min/max-width`, `min/max-height`, `overflow` (`hidden`, `scroll`, `auto`) |
| `02-padding` | `padding` shorthand, individual sides, `box-sizing: border-box` |
| `03-margin` | `margin` shorthand, `margin: auto` centering, margin collapse |
| `04-universal-selector-reset` | `* { margin: 0; padding: 0; box-sizing: border-box; }` |
| `05-border` | `border-width`, `border-style`, `border-color`, `border-radius`, `outline` |
| `06-display-property` | `block`, `inline`, `inline-block`, `none` — how elements flow |
| `07-positioning` | `static`, `relative`, `absolute`, `fixed`, `sticky` — offsets (`top`, `left`, `right`, `bottom`) |
| `08-box-shadow` | `box-shadow` syntax, multiple shadows, inset shadows |
| `09-freelance-form-project` | 🏗️ Mini-project: styled freelance contact form |
| `10-shoe-cards-project` | 🏗️ Mini-project: product card layout with positioning |

## Key Concepts
- The box model: content → padding → border → margin
- `box-sizing: border-box` and why it matters
- The difference between `position: relative` and `position: absolute`
- `position: fixed` for sticky navbars
- `position: sticky` for scroll-aware headers
