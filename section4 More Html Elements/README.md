# Section 4 — More HTML Elements

## Overview
This section explores advanced and often overlooked HTML elements — from media embeds to data tables, SVG graphics, and modern interactive elements like popovers and progress bars.

## Topics Covered

| Folder | Topic |
| :----- | :---- |
| `01-audio-element` | `<audio>` tag, `controls`, `autoplay`, `loop`, multiple sources |
| `02-video-element` | `<video>` tag, `controls`, `poster`, `muted`, `<source>` |
| `03-image-map` | `<map>`, `<area>` — clickable regions on an image |
| `04-tables` | `<table>`, `<thead>`, `<tbody>`, `<tr>`, `<th>`, `<td>`, `colspan`, `rowspan` |
| `05-iframe` | Embedding external content with `<iframe>`, YouTube embeds |
| `06-global-attributes` | `id`, `class`, `style`, `title`, `data-*`, `hidden`, `tabindex` |
| `07-svg` | Inline SVG, `<svg>`, `<circle>`, `<rect>`, `<path>`, `<line>` |
| `08-popover-details` | Native `<dialog>`, `<details>`, `<summary>`, Popover API |
| `09-progress-meter` | `<progress>` and `<meter>` elements |

## Key Concepts
- Embedding audio and video natively without plugins
- Using `<table>` correctly for tabular data (not layout)
- SVG as inline, scalable, and accessible graphics
- Modern HTML interactive elements: popovers, dialogs, details/summary
