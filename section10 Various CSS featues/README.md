# Section 10 — Various CSS Features

## Overview
This section explores powerful and modern CSS features that go beyond basic styling. You'll learn CSS custom properties (variables), filters, smooth scrolling, sticky navigation, the `calc()` function, and native CSS nesting.

## Topics Covered

| Folder | Topic |
| :----- | :---- |
| `01-custom-properties` | CSS variables with `--property-name` and `var()`, theming with `:root` |
| `02-filter` | `filter: blur()`, `brightness()`, `contrast()`, `grayscale()`, `drop-shadow()` |
| `03-smooth-scrolling` | `scroll-behavior: smooth` and `#anchor` link navigation |
| `04-sticky-navstyle` | `position: sticky` navigation that changes style on scroll (with JS) |
| `05-calc-function` | `calc()` for dynamic calculations mixing units: `calc(100% - 60px)` |
| `06-nesting` | Native CSS Nesting (`&` selector) — no preprocessor needed |

## Key Concepts
- CSS Custom Properties (Variables) — define once, use everywhere
- `:root` as the global scope for CSS variables
- CSS `filter` for image and element visual effects
- `calc()` for mixing units in a single value (e.g., `%` + `px`)
- Native CSS Nesting — writing nested rules like Sass without a build tool
- `scroll-behavior: smooth` for polished anchor link navigation
