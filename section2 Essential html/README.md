# Section 2 — Essential HTML

## Overview
This section dives deep into the core building blocks of HTML. You'll learn how to structure web pages properly using semantic elements, links, images, and more.

## Topics Covered

| Folder | Topic |
| :----- | :---- |
| `01-meta-tags-search-engines` | Meta tags, charset, viewport, SEO basics |
| `02-headings-paragraphs` | `<h1>`–`<h6>`, `<p>`, text hierarchy |
| `03-lists` | Ordered (`<ol>`), unordered (`<ul>`), description lists (`<dl>`) |
| `04-anchor-tags` | Internal links, external links, `target="_blank"`, mailto |
| `05-images` | `<img>` tag, `src`, `alt`, responsive images |
| `06-block-inline-elements` | Block vs inline elements, `<div>`, `<span>` |
| `07-br-hr-entities` | Line breaks, horizontal rules, HTML entities |
| `08-divs-and-spans` | Grouping content with `<div>` and `<span>` |
| `09-classes-and-ids` | Applying classes and IDs for targeting |
| `10-semantic-elements` | `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>` |
| `11-emmet-crash-course` | Emmet shortcuts and productivity tricks |
| `12-keyboard-shortcuts` | VS Code keyboard shortcuts for speed |
| `13-pricing-grid-challenge` | Practice challenge: build a pricing grid in HTML |

## Key Concepts
- Semantic HTML for accessibility and SEO
- Difference between block and inline elements
- HTML entities for special characters
- Emmet for faster HTML coding
