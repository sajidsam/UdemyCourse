## 📚 Course Curriculum & Section Breakdown

### HTML Fundamentals & Forms (Sections 1–4)

- **[Section 1: Introduction](<./section1%20Inroduction>)** — Setup, basic document structure, and developer workflow.
- **[Section 2: Essential HTML](<./section2%20Essential%20html>)** — Meta tags, search engines, headings, lists, links, images, block vs. inline, semantic markup, Emmet shortcuts, and pricing challenge.
- **[Section 3: HTML Forms and Input Elements](<./section3%20Html%20Form%20and%20input%20elements>)** — Text inputs, textareas, selects, radio buttons, checkboxes, datalists, input attributes, and form challenge.
- **[Section 4: More HTML Elements](<./section4%20More%20Html%20Elements>)** — Audio/video players, image maps, tables, iframes, SVG graphics, `<dialog>` / `<details>` / `<summary>`, popovers, and progress bars.

### CSS Fundamentals, Box Model & Flexbox (Sections 5–7)

- **[Section 5: CSS Basics](<./section5%20CSS%20basics>)** — Implementing CSS, selectors, system vs. Google web fonts, typography, color models (HEX, RGB, HSL), backgrounds, specificity, and Font Awesome.
- **[Section 6: Box Model and Positioning](<./section6%20Box%20Model%20and%20Positioning>)** — Content sizing, overflow, margin collapse, padding, borders, display properties (`block`, `inline`, `inline-block`, `none`), positioning (`relative`, `absolute`, `fixed`, `sticky`), box-shadows, and shoe cards project.
- **[Section 7: Flexbox](<./section7%20Flexbox>)** — Flex containers & items, main/cross axes, `justify-content`, `align-items`, `flex-wrap`, `gap`, `flex-grow`, `flex-shrink`, `flex-basis`, order, and pricing card challenges.

### Responsive Design & Modern CSS (Sections 8–10)

- **[Section 8: Responsive Design](<./section8%20Responsive%20Design>)** — Fluid layouts, percentages, `rem` & `em` typography, viewport units (`vw`, `vh`), media queries, mobile-first design, modern **Container Queries** (`@container`), and container query units (`cqi`, `cqw`).
- **[Section 9: Landing Form Mini-Project](<./section9%20Landing%20Form>)** — Complete responsive landing form interface with background assets and modern typography.
- **[Section 10: Various CSS Features](<./section10%20Various%20CSS%20featues>)** — CSS Custom Properties (variables), CSS filters, smooth scrolling, sticky navigation, `calc()` function, and native **CSS Nesting**.

### Projects, Git & Accessibility (Sections 11–13)

- **[Section 11: Lumina Creative Website](<./section11%20Lumina%20creative%20Website>)** — Full multi-page agency website built from scratch. ([Live Demo](https://lumina-creative-psi.vercel.app/))
- **[Section 12: Git &amp; GitHub Workflow](<./section12%20Github>)** — Version control fundamentals, branching, commits, `.gitignore`, and deploying projects to GitHub.
- **[Section 13: Web Accessibility (a11y)](<./section13%20Web%20Accessibility>)** — Screen reader testing, semantic landmarks, ARIA roles, ARIA expanded state, focus management, and accessibility best practices.

### Advanced Selectors & CSS Grid (Sections 14–15)

- **[Section 14: Advanced Selectors](<./section14%20Advanced%20Selectors>)** — Attribute selectors, sibling & child combinators (`+`, `~`, `>`), pseudo-elements (`::before`, `::after`), nth-child & nth-of-type formulas, image overlays, `:is()`, `:where()`, and modern `:has()` selector.
- **[Section 15: CSS Grid](<./section15%20CSS%20Grid>)** — Two-dimensional layouts, `grid-template-columns`, `repeat()`, `minmax()`, grid rows, auto-fill vs. auto-fit, line-based positioning, named grid lines, `grid-template-areas`, and fully responsive grids without media queries.

### Transitions, Animations & Capstones (Sections 16–21)

- **[Section 16: Transition &amp; Animation](<./section16%20Transition%20animation>)** — CSS transitions, timing functions, keyframe animations, hover states, and smooth UI transitions.
- **[Section 17-18: Tutor Website Project](<./section17-18%20Tutor%20Website>)** — Comprehensive full-scale course landing page with mobile menu and dynamic sections. ([Live Demo](https://tutor-site-brown.vercel.app/))
- **[Section 19-20: Leno Mobile App Website Project](<./section19-20%20Leno%20Website>)** — Large-scale capstone app showcase website with modals, interactive galleries, and custom JavaScript interactions. ([Live Demo](https://leno-apps.vercel.app/))
- **[Section 21: Production &amp; Deployment](./section21)** — Project finalization, optimization, and production deployment.

## 🛠️ Key Skills & Concepts Mastered

- **Semantic HTML5:** Native landmark elements, accessible forms, tables, media handling, and SVG integration.
- **Modern CSS Layouts:** Mastering Flexbox (1D) and CSS Grid (2D) for complex, adaptable UI patterns.
- **Responsive Web Design:** Fluid grids, media queries, mobile-first design philosophy, modern Container Queries.
- **Modern CSS Features:** CSS custom properties, native CSS nesting, `:has()`, `:is()`, `:where()`, `calc()`, and filters.
- **Web Accessibility (a11y):** Screen reader friendliness, keyboard navigation, semantic ARIA roles & attributes.
- **UI Interactivity:** Modal dialogs, mobile navigation draw-outs, smooth scroll navigation, and Lightbox galleries using Vanilla JavaScript.
- **Professional Workflow:** Clean directory organization, modular code separation, version control with Git & GitHub.

## 💻 Getting Started Locally

To explore or run any of the projects and practice sections locally:

1. **Clone the repository:**

   ```bash
   git clone https://github.com/sajidsam/UdemyCourse.git
   cd UdemyCourse
   ```
2. **Open with VS Code or any text editor:**

   ```bash
   code .
   ```
3. **Run using Live Server:**

   - Install the **Live Server** extension in VS Code.
   - Right-click on any `index.html` file (e.g., inside `section19-20 Leno Website` or `section17-18 Tutor Website`).
   - Select **"Open with Live Server"** to view it with hot-reload in your browser.
