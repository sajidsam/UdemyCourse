# Section 11 — Lumina Creative Agency Website

## Overview
A full multi-page website project for a creative agency. This is the first large-scale project in the course, combining all previously learned HTML and CSS skills into a polished, real-world website.

🔗 **Live Demo:** [lumina-creative-psi.vercel.app](https://lumina-creative-psi.vercel.app/)

## Project Structure

```
section11 Lumina creative Website/
├── index.html       # Home page
├── about.html       # About page
├── contact.html     # Contact page
├── css/
│   └── style.css    # Main stylesheet
└── images/          # All project images and assets
```

## Pages
| Page | Description |
| :--- | :---------- |
| `index.html` | Home page with hero, services, and portfolio sections |
| `about.html` | Team showcase and agency story |
| `contact.html` | Contact form with address and social links |

## Features
- Multi-page routing with consistent navigation header and footer
- Responsive layout using Flexbox
- Interactive portfolio gallery with Lightbox2 integration
- Team member cards and services overview grid
- Accessible contact form
- Social media links

## Skills Applied
- Semantic HTML5 across multiple pages
- CSS Flexbox for layout
- Responsive design with media queries
- Lightbox2 library for image gallery
- Font Awesome for icons
- Google Fonts for typography
