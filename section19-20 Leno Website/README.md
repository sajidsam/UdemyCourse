# Section 19-20 — Leno Mobile App Website Project

## Overview
A large-scale capstone project — a modern, high-converting landing page for **Leno**, an all-in-one productivity and health assistant mobile application. This project features modals, interactive galleries, testimonials, a pricing table, and custom JavaScript interactions.

🔗 **Live Demo:** [leno-apps.vercel.app](https://leno-apps.vercel.app/)

## Pages
| Page | Description |
| :--- | :---------- |
| `index.html` | Full-featured app landing page |
| `details.html` | Detailed app features and screenshots page |

## Sections on the Page
1. **Navbar** — Responsive navigation with mobile hamburger menu
2. **Hero** — Bold hero with app mockup, CTA buttons (App Store / Play Store)
3. **Video Section** — Embedded video preview with modal popup
4. **Features** — App feature highlights with icons and descriptions
5. **Screenshots** — Interactive screenshot gallery with modal viewer
6. **Testimonials** — User review cards / grid
7. **Pricing** — Pricing tiers / plans table
8. **Newsletter** — Email download / subscribe CTA
9. **Footer** — Links, social icons, and copyright

## Features
- ✅ Fully responsive layout (mobile, tablet, desktop)
- ✅ Animated mobile hamburger menu
- ✅ Video modal popup — click to open video in a modal overlay
- ✅ Screenshots gallery with interactive modal viewer
- ✅ Testimonials section with user reviews
- ✅ Pricing table with plan comparison
- ✅ Accessible markup with ARIA attributes
- ✅ Font Awesome icons and Google Fonts

## Skills Applied
- Semantic HTML5 across multiple pages
- CSS Flexbox and Grid for complex layouts
- Responsive design with media queries
- CSS custom properties (variables) for theming
- CSS transitions and keyframe animations
- Vanilla JavaScript: modal dialogs, event listeners, DOM manipulation
- Mobile-first design philosophy
